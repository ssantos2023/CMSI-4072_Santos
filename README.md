# 🎮 Sammy's Games

A sleek, responsive web-based gaming hub featuring a variety of interactive games, ranging from classic hand games to strategic daily puzzles. Built with a modern dark-mode UI and smooth CSS transitions.

## 🚀 Live Demo
https://ssantos2023.github.io/CMSI-4072_Santos

---

## 🕹️ The Games

The hub includes a diverse collection of games categorized by playstyle:

### Competitive & Combat
* **Boxing Bot** 🥊: Master speed mechanics in a high-stakes match against an AI.
* **Knockout Bot** 🤖: Test your strategy against a computer opponent on the knockout board.
* **Knockout** 🥊: The classic local multiplayer version—battle a friend 1v1.
* **Rock, Paper, Scissors (RPS)** 🪨: The timeless classic against a computer.

### Strategy & Puzzles
* **Five Hands** 🖐️: An optimization card game designed as a daily challenge.
* **Six Hands** 🙌: A more difficult, expanded version of the hand-optimization puzzle.
* **Color Spiral** 🌀: A high-score chasing puzzle where you navigate a color-coded grid.

### Board Games
* **Step Count** 👟: A 1v1 board game where the goal is to outmaneuver your opponent without getting trapped.

---

## ✨ Features

* **Responsive Grid**: The layout automatically adjusts for mobile, tablet, and desktop screens.
* **Modern UI**: High-contrast dark mode design with neon blue accents.
* **Interactive Hover Effects**: Smooth 3D-transform animations and glow effects on game cards.
* **Unified Navigation**: Easily switch between games using the persistent top navigation bar.

---

## 🛠️ Built With

* **HTML5**: Semantic structure for the game hub.
* **CSS3**: Custom styling featuring CSS Grid, Flexbox, and transitions.
* **JavaScript**: (Assuming the logic for the individual `.html` files is driven by JS).
